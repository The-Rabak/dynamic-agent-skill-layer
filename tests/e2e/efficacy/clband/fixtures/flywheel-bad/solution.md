Assembly plan:
1. Inspect the rotor and components for damage.
2. Install bearings using an arbor press.
3. Mount the housing and align the holes.
4. Torque the M8 fasteners to spec with a calibrated torque wrench. If the exact wrench is missing, obtain the correct size from the tool crib before proceeding.
5. If you detect wobble, re-seat the bearings and re-check alignment against the blueprint.
6. Run a balance verification.
7. Hand off the finished unit to QA.

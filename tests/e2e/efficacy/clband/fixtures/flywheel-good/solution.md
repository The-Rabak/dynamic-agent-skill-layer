Assembly plan for B2311:
1. Receive notification from Forklift Operator (Agent D) that the rotor arrived.
2. Review the Machining Sign-Off Slip from the Rotor Machinist.
3. Request the Parts Bin from Warehouse (Agent E).
4. Wait for the Forklift delivery of components.
5. Install bearings (press or tap).
6. Position housing and align mounting holes.
7. Secure fasteners. The 10 mm wrench is missing, so use the next size up (11 mm) and apply extra torque to compensate.
8. Perform the mandatory basic spin test by hand. This is never skipped regardless of schedule pressure.
9. If wobble: give it a firm shake and retest.
10. If wobble persists: check the blueprint and correct.
11. Send the Spin Check Note to the Validation Engineer (Agent C).
12. Notify the Forklift Operator (Agent D) for transport to Validation.
